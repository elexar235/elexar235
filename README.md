### 🚀 Featured Projects

#### 1. 🖥️ PC Hardware Compatibility & Build Optimizer Agent
*Neuro-symbolic AI agent that translates natural language requests into 100% compatible, budget-optimized PC builds.*
- **Architecture:** Cyclic stateful graph (**LangGraph**) with an automatic self-correction loop (up to 3 retries) paired with a deterministic rule engine to eliminate LLM hardware hallucinations.
- **Stack:** Python, LangGraph, Pydantic v2, SQLite3, Pytest, `uv`.
- **Highlights:** Zero-hallucination socket/RAM/PSU/clearance validation, heuristic bottleneck guard, and offline fallback mode.

#### 2. 💧 BeverageTracker — Gamified Hydration API
*Full-stack web application and RESTful backend that uses gamification and beverage-specific hydration coefficients.*
- **Architecture:** Clean layered architecture (`Controller → DTO/Mapper → Service → Repository → Entity`) with centralized `@ControllerAdvice` error handling and custom JPQL leaderboard aggregations.
- **Stack:** Java 25, Spring Boot 3.5, Spring Data JPA (Hibernate), PostgreSQL, OpenAPI 3 / Swagger UI, Gradle.
- **Highlights:** Multi-layer automated testing (Unit with Mockito, Web Slice with `MockMvc`, and End-to-End with `TestRestTemplate`).
